# Screen Protector

Screen Protector 是一款轻量级的 Windows 桌面应用程序，旨在通过自动调节屏幕亮度来保护用户的眼睛。当检测到用户长时间未操作电脑时，应用会自动将屏幕亮度降至最低，减少蓝光辐射和眼睛疲劳。

**✨ 特别推荐笔记本用户使用！** 该应用不仅能保护眼睛，还能有效**防止 OLED 屏幕烧屏**、**延长笔记本续航时间**。作者已在自己的笔记本上进行了充分验证，**稳定好用，值得信赖**。

## 主要功能

- **自动亮度调节**：根据用户设定的空闲时间阈值，自动降低屏幕亮度，保护眼睛。
- **空闲自动黑屏**：勾选「空闲时进入黑屏」，达到同一空闲时间阈值后显示全黑遮罩；不勾选则保持自动降亮，选择会自动保存。
- **OLED 屏幕烧屏防护**：通过自动降低亮度和基础屏幕保护，有效防止 OLED 屏幕烧屏现象。
- **延长笔记本续航**：降低屏幕亮度可显著降低屏幕功耗，延长笔记本电池续航时间。
- **手动亮度调节**：提供滑动条和输入框，允许用户手动调节屏幕亮度。
- **手动黑屏保护**：通过界面按钮或托盘菜单，用全黑遮罩覆盖所有显示器，移动鼠标或按键退出。
- **RDP 屏幕保护**：启用自动切换时，远程桌面连接自动关闭遮罩，保存笔记本硬件亮度并降至最低；回到本机活动会话或退出程序时恢复原亮度。本机的空闲保护设置会保留，回到本机后重新计时。
- **手动/自动模式切换**：黑屏保护区域提供「本机模式（遮罩）」和「远程模式（降亮）」。默认勾选「根据 RDP 连接自动切换模式」；取消勾选即可手动选择，模式与自动切换偏好会保存。
- **开机自启动**：支持设置开机自动启动，确保功能始终生效。
- **系统托盘集成**：最小化到系统托盘，不占用任务栏空间，方便快速访问。
- **个性化设置**：允许用户自定义空闲时间阈值和亮度级别。

## 使用方法

1. **启动应用**：运行 `ScreenProtector.exe` 启动应用。
2. **设置空闲时间**：在应用界面中调节「空闲时间」滑动条，设置自动降低亮度的空闲时间阈值（单位：秒）。
3. **启用自动保护**：打开「启用空闲检测」，按需勾选「空闲时进入黑屏」。勾选后到达设定时长时显示全黑遮罩，未勾选时自动降低亮度。每次持续空闲只触发一次，恢复操作后重新计时；设为 0 秒可禁用自动保护。
4. **手动调节亮度**：使用「亮度」滑动条或输入框，手动调节屏幕亮度。
5. **手动黑屏**：点击「进入黑屏」按钮，或从托盘菜单选择「进入黑屏」。移动鼠标、点击或按任意键即可退出黑屏。
   **选择保护模式**：取消「根据 RDP 连接自动切换模式」后，可在下拉框手动选择本机或远程模式。远程模式立即降低实体屏幕亮度，切回本机模式恢复原亮度并重新开始空闲计时。本机模式的遮罩仍只在本机活动会话显示。勾选自动切换后，下拉框显示当前模式，由 RDP 连接状态控制。
6. **开机自启动**：勾选「开机自启动」复选框，设置应用随系统启动。
7. **最小化到托盘**：点击最小化按钮，应用将隐藏到系统托盘，双击托盘图标可恢复窗口。

## 命令行参数

- `-startup`：以静默模式启动应用，直接隐藏到系统托盘。

## 注意事项

- 应用需要管理员权限才能调节屏幕亮度。
- 部分显示器可能不支持 WMI 亮度调节，此时应用将无法调节亮度。
- 黑屏使用全黑窗口覆盖显示器，显示器仍保持通电。遮罩显示期间保持屏幕和系统唤醒，退出后释放唤醒请求。
- 黑屏不会修改电源方案或 Windows 登录设置。Windows 的独立安全策略和手动锁屏仍可生效；本程序避免因空闲关闭显示器而触发重新登录。
- RDP 会话和未连接到本机的会话中不会显示遮罩；界面和托盘的黑屏入口自动暂停，原勾选状态仍保留。远程模式通过 WMI 降低笔记本实体屏幕的亮度，远程画面不被遮罩覆盖。
- 降至最低亮度不等于关闭显示器。实际关屏继续由现有 Windows 电源策略决定，程序不会更改关屏、睡眠或登录设置。外接显示器及不支持 WMI 的屏幕无法使用此降亮方式，失败会显示提示。
- 自动切换时，回到本机或正常退出程序会恢复原亮度，RDP 断开后保持低亮度直到本机返回；手动模式下，切回本机模式或正常退出恢复原亮度。恢复失败会保留原值并重试，退出失败时程序会提示并保持运行。
- 如需卸载，请先关闭应用并删除启动项。
